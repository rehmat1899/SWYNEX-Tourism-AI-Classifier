# AI-Based Smart Tourism Question Classification System

## Project Overview
This project is a Machine Learning-based system that classifies tourists' questions into five categories.

## Categories
1. Attractions
2. Routes
3. Accommodation
4. Weather
5. Safety

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Google Colab

## Dataset
The project uses a self-created dataset containing 100 sample questions, with 20 questions in each category.

## Model Performance
- Model Accuracy: 95%
- Test Samples: 20

*Note: This result is based on the current test split and does not guarantee the same accuracy on real-world questions.*

## Project Files
- `SWYNEX_Tourism_AI_Model.ipynb` — Python notebook
- `tourism_model.pkl` — Trained model
- `tfidf_vectorizer.pkl` — TF-IDF vectorizer

## Example
**Input:** What is the weather in Murree?

**Predicted Category:** Weather

## Purpose
This project demonstrates how Machine Learning can help automatically classify tourism-related questions.
